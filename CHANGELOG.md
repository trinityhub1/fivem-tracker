# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - Unreleased

### Added
- Server lookup by Cfx ID or `cfx.re/join/...` link
- Live server status, name, player count, and capacity
- Live player list with search and sort
- Session statistics (peak/average/low population, ping)
- Favourites via `localStorage` (no account required)
- Shareable, deep-linkable server URLs (`#/server/<id>`)
- Auto-refresh with configurable interval
- Dark / light / system theme
- Mobile-first responsive layout
- GitHub Pages deployment workflow
